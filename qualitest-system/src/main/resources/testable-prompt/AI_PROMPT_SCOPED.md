本文件供顶栏「MCP 造流 Agent 规程」弹框读取「指定范围」示例提问。
文件开头到下方分隔线为说明；接口只返回分隔线之后的正文。

用法：复制后把 `<指定范围>` 换成模块名 / 包路径 / 目录，再贴到 Cursor 等 AI 编辑器。

---

自行阅读本仓库 `<指定范围>` 内的业务代码与文档，列出可直接贴进质衡测试流 AI 的短提示。
每个子能力先给主路径，重要写操作再补失败/拒绝类提示（以代码里真实分支为准）。
每条用业务语言写步骤、测值和期望结果；不要写 URL 与接口编排细节。
测值从仓库文档与种子数据读取；读不到标「不确定」。
不要扩到范围外；按子能力分段输出，便于分批粘贴。
登录一般由质衡项目里已挂的登录流覆盖，提示里不用重复写，除非本条就是在测登录。
直接开始列提示，不要再问我范围是什么。
