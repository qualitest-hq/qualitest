---

对照本仓库里你刚改过 / 当前对话相关的那一块业务（git 未提交改动、最近提交或当前打开的文件均可，你自己判断范围），为质衡测试流 AI 写出若干条短提示。
每条只测一个意图；用业务语言写步骤、测值和期望结果。
不要写 URL、HTTP 方法、JSONPath；不要写成长篇方案。
测值从 README、配置、种子数据里取；读不到就标明「不确定」，不要编造 ID。
只覆盖本次改动相关能力，不要扩到无关模块。
登录一般由质衡项目里已挂的登录流覆盖，提示里不用重复写，除非本条就是在测登录。
直接输出短提示列表，不要再问我指定 diff 或目录。
