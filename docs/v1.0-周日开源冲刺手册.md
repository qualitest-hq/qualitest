# v1.0 周日开源冲刺手册

> **用途**：周日一天内完成「主链路冒烟」→「阶段 0 轻量整理」→「阶段 1 可公开最小包」→ 推 GitHub 首发。  
> **工作区**：`qualitest-all`（`qualitest`（含 `qualitest-ui/`）· `qualitest-demo` · `qualitest-intellij-plugin`）  
> **远程**：GitHub Org [`qualitest-hq`](https://github.com/qualitest-hq)（当前 Private）  
> **默认账号**：质衡 `admin` / `admin123`（以种子 SQL 为准）  
> **关联**：总路线图见 [质衡开源与工程路线图.md](./质衡开源与工程路线图.md)

## A. 环境拉起（冒烟前）

### A.1 依赖

- JDK ≥ 17、Maven ≥ 3、MySQL ≥ 8、Redis ≥ 3、Node + Yarn
- 本机端口空闲：**8080**（质衡）、**5173**（UI）、**8081**（demo）

### A.2 质衡主平台

```text
1. 建库 qualitest
2. 导入 sql/qualitest_*.sql（取最新一份）
3. 确认 qualitest-admin/.../application-dev.yml 库账号 / Redis 可用
4. 根目录：mvn clean package -DskipTests  或  qualitest.bat / qualitest.sh
5. 前端：`cd qualitest-ui && yarn install && yarn dev`（前端在主仓子目录）
6. 浏览器：http://localhost:5173  →  admin / admin123
```

### A.3 靶场 demo（冒烟强烈建议开）

```text
1. 建库 qualitest-demo，导入 sql/qualitest-demo_*.sql
2. 改 demo-admin/.../application-dev.yml
3. mvn clean install && demo.bat（或 demo.sh）
4. Swagger：http://localhost:8081/swagger-ui.html
```

### A.4 端口对照

| 服务 | 端口 | 作用 |
|------|------|------|
| qualitest API | 8080 | 主平台后端 |
| qualitest-ui（主仓子目录） | 5173 | Web |
| qualitest-demo | 8081 | 被测靶场 |

## B. 完整测试流程（冒烟清单）

> 目标：确认「可演示主链路」都通。失败项记到文末「冒烟问题」。  
> 打勾规则：亲自点过 / 跑过才勾。

### B.1 登录与项目

- [ ] 登录成功，进入首页 / 项目列表
- [ ] 打开（或新建）一个测试项目，能进项目详情
- [ ] 环境管理：新增或编辑环境，`baseUrl = http://localhost:8081`
- [ ] （可选）环境开启「允许还原被测数据」——若开，记住：**同一环境串行跑**

### B.2 接口资产（二选一即可）

**路径 1 · IDEA 插件（有插件时）**

- [ ] 插件连 `http://localhost:8080`，选中项目上传
- [ ] 质衡「接口管理」出现 Controller / 接口树

**路径 2 · 手工 / 已有数据**

- [ ] 项目内已有接口资产，或手工录入 1～2 个 demo 接口（如登录、下单相关）

### B.3 接口调试台

- [ ] 选中接口，切到 demo 环境，发请求成功（有响应体 / 状态码）
- [ ] 换一个会失败的路径或错误参数，确认失败可见（非白屏）

### B.4 靶场场景（demo）

- [ ] demo 管理端进入「测试场景」，加载一个场景（如 S01）
- [ ] Swagger 或质衡调试台能用场景推荐账号打通 1 次客户端调用

### B.5 测试流编排

- [ ] 新建或打开一条测试流，画布可见
- [ ] 至少串联：**HTTP → 断言**（或条件 / 脚本其一）
- [ ] 保存后执行 Run，状态为通过或失败（非卡住无状态）
- [ ] 打开 Run 详情：步骤时间线、HTTP 面板可读

### B.6 快照 / 暂停（已交付能力，抽测）

- [ ] 某写节点勾选 `snapshotBefore`；环境已允许还原
- [ ] 故意让后续节点失败 → Run 进入 `paused`
- [ ] Run 详情可见决策按钮（还原重试 / 原地重试 / 跳过 / 中止），任选一种能继续或结束
- [ ] （可选）curl 验收 demo：`POST /test-support/snapshot` 与 `restore`（见 starter README）

### B.7 AI Diff（有可用 LLM 时）

- [ ] 测试流旁打开 AI 助手，用一句自然语言提修改建议
- [ ] 出现 Diff / Staging，**确认合并**后画布有变化；取消不脏写

> 无 Key / 模型不可用：标 **跳过**，不阻塞开源（README 写清需自备模型）。

### B.8 MCP（有 Cursor 时）

- [ ] 项目设置生成 Token，按说明写入 Cursor `mcp.json`
- [ ] 能调用只读工具（如列测试流 / 看 Run）至少 1 次

> 无 Cursor：标 **跳过**；阶段 1 仍建议补 `docs/mcp.md` 占位说明。

### B.9 冒烟结论

| 结果 | 含义 |
|------|------|
| B.1～B.5 全绿 | 可进入阶段 0/1 冲刺 |
| B.6 失败 | 开源前关掉「还原」演示文案，或修后再发 |
| B.7 / B.8 跳过 | 可发 v1.0，文档标明可选能力 |
