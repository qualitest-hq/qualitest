| 文件 | 用途 |
|------|------|
| `overview.gif` | Hero 概览；缺失时回退链路 SVG |

| `demo-mcp-autowrite.gif` | MCP 区块 · 造流 / 跑通 |

公开前若尚未录制：

- Hero：自动用链路 SVG
- MCP 区块：显示文件名占位提示，GIF 就绪后自动替换
